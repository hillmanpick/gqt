# 实时全市场信号

GQT Trader 的行情页会扫描 Binance USDT-M 永续合约，并对成交额、动量、资金费率和候选持仓量进行排序。扫描器每 15 秒刷新一次市场数据，每 60 秒刷新一次新闻和社交事件。

## 舆情来源

系统使用合规的授权接口，不抓取登录后的 X/Twitter 页面：

- 默认读取 CoinDesk 和 Cointelegraph RSS，作为无密钥的基础新闻源。
- `GQT_X_BEARER_TOKEN` 配合 `GQT_X_SEARCH_URL` 接入 X API v2 recent search。
- `GQT_NEWS_JSON_URL` 接入授权 JSON 新闻源，密钥通过 `GQT_NEWS_API_KEY` 发送为 `X-API-Key`。
- `GQT_NEWS_RSS_URL` 可覆盖默认 RSS 地址；多个地址用英文逗号分隔。

X 搜索 URL 需要由用户按自己的 API 套餐和限流策略配置，例如包含 `query`、`tweet.fields=created_at,public_metrics` 和 `max_results` 参数。密钥只从进程环境读取，不写入仓库。

每条事件会记录来源、作者、发布时间（UTC）、币种、事件类型、方向、可信度、互动量、机器人折扣和文本指纹。相同 URL、转发链和相似文本会去重。界面显示北京时间（UTC+8），数据库统一保存 UTC 时间戳。

## 推荐门槛

行情分占 70%，舆情方向和质量占 30%。没有舆情证据、来源过于单一、舆情与行情反向或数据过期时不会生成可执行推荐。推荐中的杠杆是硬上限：主流币最高 50 倍，山寨币最高 5 倍；实际建议值还会按波动率、价差和流动性下调。

推荐默认只展示和纸面跟踪，不会因为新闻文本直接发送订单。向量检索可以在后续加入，用于查找相似历史事件；事件时间、评分、来源和收益标签仍以 SQLite 结构化记录为准。
